# 正方体阵列可视化工具

基于 Bevy 0.18.1 和 Rust 开发的 3D 正方体阵列可视化软件，使用 GPU Instancing 实现 1,048,576 个正方体的高性能渲染。

## 功能

- **正方体阵列**: 64（X/左右）× 1024（Y/深度）× 16（Z/上下）= 1,048,576 个正方体
- **横截面查看**: 通过 UI 滑块选择任意 X/Y/Z 层，其余层隐藏
- **轨道相机**: 鼠标左键拖动旋转视角，滚轮缩放
- **ESC 重置**: 一键恢复全部正方体显示并重置滑块
- **FPS 显示**: 右上角实时帧率显示

## 使用方法

### 运行

```bash
cargo run
```

### 操作

| 操作 | 方式 |
|------|------|
| 旋转视角 | 鼠标左键拖动 |
| 缩放 | 鼠标滚轮 |
| 横截面查看 | 拖动底部面板 X/Y/Z 滑块 |
| 恢复全部显示 | 按 ESC 键 |

### 滑块说明

- 滑块值 0 = 该轴显示全部层
- 滑块值 1~N = 仅显示该轴第 N 层（横截面模式）
- X 轴: 0-64（左右）
- Y 轴: 0-1024（深度）
- Z 轴: 0-16（上下）

## 技术架构

```
bevy_cube_viewer/
├── Cargo.toml
├── assets/shaders/
│   └── cube_grid.wgsl          # 自定义 WGSL 着色器（漫反射光照+边缘暗化）
└── src/
    ├── main.rs                  # 应用入口、插件注册、ESC处理
    ├── cube_grid.rs             # 网格数据、颜色、可见性计算
    ├── cube_material.rs         # 自定义渲染管线、GPU实例缓冲
    ├── ui.rs                    # 横截面滑块 UI
    └── camera.rs                # 轨道相机系统
```

## 依赖

- **Bevy 0.18.1**: ECS 游戏引擎（本地路径 `../../bevy`）
- **bytemuck**: GPU 数据安全转换
- **bevy_dev_tools**: FPS 覆盖层
- **bevy_ui_widgets**: 滑块 UI 组件（experimental）

## 着色器效果

自定义 WGSL 着色器提供：
- **漫反射光照**: 不同朝向的面有明暗区分，增强立体感
- **边缘暗化**: 每个面边缘略微变暗，便于区分相邻正方体
