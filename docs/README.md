# 正方体阵列可视化工具

基于 Bevy 0.18 和 Rust 开发的 3D 正方体阵列可视化软件，使用 GPU Instancing 实现 1,048,576 个正方体的高性能渲染（单次 DrawCall）。

## 功能

- **正方体阵列**: 64（X/左右）× 1024（Y/深度）× 16（Z/上下）= 1,048,576 个正方体，随机白/红/灰三色
- **横截面查看**: 通过 UI 滑块选择任意 X/Y/Z 层，其余层隐藏
- **视图切换**: 底部按钮切换 3D 自由视角 / X 剖面 / Y 剖面 / Z 剖面
- **悬停拾取**: 鼠标悬停时通过 DDA 射线遍历识别网格坐标，高亮显示并弹出浮动标签
- **坐标面板**: 右下角实时显示当前悬停的网格坐标
- **轨道相机**: 3D 模式鼠标左键旋转/滚轮缩放；剖面模式鼠标左键平移/滚轮缩放
- **ESC 重置**: 一键恢复全部正方体显示并重置滑块
- **FPS 显示**: 右上角实时帧率显示

## 使用方法

### 运行

```bash
cargo run
```

### 操作

| 操作 | 方式 |
|------|------|
| 旋转视角 (3D 模式) | 鼠标左键拖动 |
| 平移视角 (剖面模式) | 鼠标左键拖动 |
| 缩放 | 鼠标滚轮 |
| 切换视角 | 底部按钮栏 — 3D / X 剖面 / Y 剖面 / Z 剖面 |
| 横截面查看 | 拖动底部面板 X/Y/Z 滑块 |
| 网格坐标拾取 | 鼠标悬停在正方体上 |
| 恢复全部显示 | 按 ESC 键 |

### 滑块说明

- 滑块值 0 = 该轴显示全部层
- 滑块值 1~N = 仅显示该轴第 N 层（横截面模式）
- X 轴: 0-64（左右）
- Y 轴: 0-1024（深度）
- Z 轴: 0-16（上下）

## 颜色说明

正方体随机初始化为三种颜色：

| 值 | 颜色 | 用途 |
|----|------|------|
| 0 | 白色 | 默认 |
| 1 | 红色 | 标记 |
| 2 | 灰色 | 标记 |

悬停的正方体会被 shader uniform 替换为金色高亮。

## 技术架构

```
bevy_cube_viewer/
├── Cargo.toml
├── assets/shaders/
│   └── cube_grid.wgsl          # 自定义 WGSL 着色器（漫反射光照 + 边缘暗化 + 悬停高亮）
└── src/
    ├── main.rs                  # 应用入口、插件注册、ESC 处理、系统编排
    ├── cube_grid.rs             # 网格数据 (CubeGrid)、颜色、坐标计算、可见性筛选
    ├── cube_material.rs         # 自定义渲染管线、GPU 实例缓冲、HoverUniform
    ├── camera.rs                # 轨道相机、视图模式切换 (ViewMode)
    ├── ui.rs                    # 横截面滑块、视图按钮、坐标面板、浮动标签
    └── picking.rs               # DDA 射线遍历、悬停拾取 (PickingState)
```

## 渲染架构

- **GPU Instancing**: 所有正方体共享同一 Mesh (1×1×1 Cuboid)，通过实例缓冲传递 per-instance 位置和颜色
- **单次 DrawCall**: 1,048,576 个正方体由 `DrawMeshInstanced` 一次绘制
- **Shader Uniform 高亮**: 悬停坐标通过 16 字节 HoverUniform (bind group 3) 传递到顶点着色器，避免每帧重建 32MB 实例缓冲
- **DDA 遍历**: 从相机射线在网格 AABB 上的入点开始，沿射线步进，检查横截面可见性后返回命中坐标

## 依赖

- **Bevy 0.18**: ECS 游戏引擎（本地路径 `../../bevy`）
- **bytemuck**: GPU 数据零拷贝安全转换
- **rand**: 正方体颜色随机初始化
- **bevy_dev_tools**: FPS 覆盖层
- **bevy_ui_widgets**: 滑块 UI 组件 (experimental)
